## 上游升级策略

- 小型独立修复：评估后 cherry-pick 或按当前代码重写。
- 社区未合并 PR：只提取协议和测试思路，默认重写。
- 新 RC 或正式版：从新上游标签建立新的升级线，再重放 SXH 能力；不要强制改写已发布稳定线。
- 合并冲突优先保护计费、数据库兼容、请求重放和部分流语义，不以“能编译”为完成标准。
