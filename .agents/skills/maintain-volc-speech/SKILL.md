# 维护火山语音适配

## 开始前

1. 读取 [references/volc-speech-contract.md](references/volc-speech-contract.md)。
2. 读取 `docs/volc-speech.md`；涉及客户端协议时继续读取 `docs/volc-speech-client.md`。
3. 检查 `git status --short`，确认改动边界。
4. 上游协议、模型或价格可能变化时，只使用火山官方文档重新核实；不要从旧实现反推最新协议。

## 实现原则

- 始终使用 `EffectiveUpstreamModelName()` 或等价映射结果识别上游模型，禁止在适配器写死 `sxh-tts`、`sxh-asr`。
- 协议、资源 ID 和鉴权头由服务端决定，不接受客户端 metadata 覆盖。
- 单段 Key 与 `appid|access_token` 两种鉴权保持兼容，不记录凭据。
- 普通裸音频路径必须保持兼容；字幕扩展只在显式请求时启用。
- 首字节前允许符合规则的渠道重试；输出后必须禁止切换，标记部分流失败并退回预扣。
- 不伪造、拆分、均分或纠偏火山时间轴；标点、数字和空格保留上游语义。
- 不在源码硬编码易变价格；未配置价格时不得免费调用。

## 变更检查

按完整链路检查，不只看适配器：

1. DTO 与请求解析。
2. 业务模型到上游模型的映射。
3. 参数验证和 multipart 重放。
4. 上游请求、鉴权、响应解析和流式写入。
5. 预扣、实际用量结算、失败退款。
6. 审计日志与隐私。
7. OpenAPI、客户端文档和发布日志。

## 验证

至少执行：

```bash
go test -timeout 10m ./...
go test -race ./relay/channel/volcengine ./relay/helper -run 'Volc|Mapped'
git diff --check
```

涉及前端或镜像时继续执行仓库当前的前端类型检查、构建和 Docker 构建。

真实联调必须使用生产数据库副本、隔离端口和最小音频；不得读取输出密钥、修改生产渠道或把完整文本、音频、字幕写入日志。验证业务模型映射、音频可还原、事件顺序、时间单位、实际结算和隐私字段。

### 生产快照基线

1. 首次联调使用 SQLite 一致性备份建立只读基线，不直接复制正在写入的数据库文件。基线放在仓库外，权限限制为当前用户读写，并记录抓取时间、生产版本、文件 SHA-256、`PRAGMA integrity_check` 和不暴露敏感值的配置指纹。
2. 基线保持不可变。每次启动隔离实例前复制出一次性工作库；联调产生的日志、扣费、Token 状态和其他写入只能进入工作库，结束后不得把它当作新基线。
3. 同一候选线可以复用基线，不要求每次下载生产数据库。复用前只读比较数据库结构以及渠道状态/类型、模型映射、模型定价、分组倍率和测试 Token 权限等相关配置指纹。
4. 数据库迁移、渠道或凭据变化、模型映射/定价/权限变化、生产版本或关键环境变量变化、相关事故调查，以及基线完整性或来源不明确时必须刷新。无法可靠比较指纹时也应刷新，不以文件日期代替一致性判断。
5. 配置指纹、清单和命令输出不得包含 Key、Token、完整用户数据或可逆敏感字段；快照不得提交、上传到制品库或长期散落在临时目录。
6. 工作区源码联调只用于提前发现问题。正式候选验收必须对已合并提交构建的唯一标签镜像重复执行，不能用 `go run` 或未提交工作区替代候选镜像。

## 交付

- 独立 review 与修订分开进行。
- 在 PR 中列出普通 TTS、ASR JSON/text、方舟聊天/图像和其他渠道的回归边界。
- 候选镜像通过后也不得自动上线；生产操作改用 `$operate-new-api-production`。
