# 运维 new-api 生产

## 权限边界

- “查看、分析、评估”只允许只读检查。
- 只有用户明确要求上线、禁用渠道、修改配置、迁移数据库或回滚时，才能执行对应生产写操作。
- 生产发布授权不自动包含数据库迁移、渠道变更或 manager 发布。
- 不输出或复制 Key、Token、完整请求正文、音频和数据库敏感字段。

## 开始前

1. 读取 [references/production-runbook.md](references/production-runbook.md)。
2. 检查本地分支、提交、工作区和候选版本。
3. 只读确认线上容器、镜像、启动时间、挂载、数据库类型、磁盘空间、日志和相邻服务。
4. 比较候选提交与线上提交，列出数据库迁移、环境变量和回滚影响。
5. 工作区不干净、候选镜像与提交不一致、备份不可验证或数据路径不明确时停止发布。

## 渠道故障诊断

1. 同时检查最终 HTTP 状态、宿主机 Docker/Nginx 日志、渠道状态和对应版本源码。
2. 不把 `priority` 当作健康检查；它只决定初始选择。
3. 核对 `RetryTimes`、全局自动禁用/恢复开关、渠道 `auto_ban`、定时测试和错误分类。
4. SQLite 类型 5 日志不完整时，以 Docker/Nginx 最终请求证据补充。
5. 504/524 可能已经产生上游请求或计费，不得全局放宽重试；按模型和“首字节前/后”限定。
6. 容器没有 shell 时改用宿主机日志、SQLite 和 `docker inspect`，不要临时改镜像。

## 发布

1. 创建带时间戳的数据库备份并执行完整性检查，记录权限、大小和 SHA-256。
2. 使用唯一版本与提交号构建候选产物；先上传到临时名称并核对本地/远端制品 SHA-256。不同 Docker 存储后端导入同一制品后 image ID 或显示大小可能不同，不得只据此判失败；继续比较 RootFS diff IDs、入口与环境配置、版本/提交标签及应用二进制 SHA-256。
3. 保留当前镜像、二进制和 Compose 配置作为回滚点。
4. 只重建或切换 `new-api` 服务，不重启 manager、Nginx 或数据库，除非它们明确在授权范围内。
5. 记录旧容器停止事件、新容器启动事件和首次健康成功时间。只有捕获到旧容器停止时间时才报告实际中断；从 Compose 命令开始计时只能报告“可用性恢复上界”。

### 连续空窗快速切换

1. 停旧实例前完成镜像构建、上传/加载、SHA-256 核对、Compose 候选准备、数据库备份、回滚命令和候选隔离验证；切换窗口内不得再下载依赖或现场构建。
2. 发布前定义连续空窗长度、最大等待时间和回滚阈值。监控 Nginx 最终请求、应用在途指标以及容器网络活动；TCP `ESTABLISHED` 包含空闲 keep-alive，连接数不归零不能单独证明仍有请求。
3. 只有连续空窗成立并在停机前完成最后一次在途检查后才能切换。若已有安全的 drain/入口闸门，先停止接收新请求再等待在途归零；修改 Nginx 或其他入口必须在本次授权范围内。
4. 没有应用在途指标或 drain 时，检查连接收发队列、最近数据活动时间及连续完成日志，只能缩小风险，不能声称在途严格归零。当前单实例 SQLite 拓扑不得为了蓝绿临时并行挂载同一数据目录。
5. 空窗确认后只停止并重建 `new-api`，立即检查容器运行、版本和健康接口；超过回滚阈值或启动失败时切回已保留旧镜像。记录从旧实例停止到新实例健康的实际秒数。

## 上线验收

- 容器运行且镜像标签、版本、提交号与候选一致。
- 数据挂载仍指向原持久化目录；SQLite 只读查询设置 busy timeout 并有限重试。区分应稳定的结构/配置计数与可能因线上流量增长的 Token、日志计数。
- 先从 Nginx 配置确认域名和路径的真实上游，再检查内部健康、公开状态、管理端接口和至少一个低成本业务请求；不要假设 API 域名的 `/api/status` 一定转发给 new-api。
- 检查严重日志、渠道选择、计费和退款审计。
- 相邻 manager 服务的镜像、启动时间和数据保持不变。
- 报告未验证边界；构建通过不能替代线上请求和数据验证。

涉及火山语音且已取得生产真实请求授权时，运行：

```bash
python3 .agents/skills/operate-new-api-production/scripts/validate-volc-speech-production.py \
  --base-url <PUBLIC_API_BASE_URL> \
  --db <SQLITE_PATH> \
  --token-id <DEDICATED_TEST_TOKEN_ID> \
  --confirm-live-request
```

脚本从 SQLite 内部读取启用限额的专用测试 Token 但不输出凭据，执行最小 TTS→ASR 请求，并按请求 ID 核对计费、Token 变化和日志隐私。不得在未授权时运行。

## 回滚

- 应用回滚优先切回保留的旧镜像或二进制。
- 只有确认数据库发生不兼容写入时才考虑恢复数据库备份；恢复前必须再次获得明确授权并停止写入。
- 回滚后重复完整验收，并保留失败版本的日志、镜像和数据库副本供分析。
