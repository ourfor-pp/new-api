# v1.0.0-rc.22-sxh.6 候选版本日志

## 版本目标

本版本在已上线的 `.5` 上增加当前两个火山资源真实支持的厂商中立语音扩展。接口继续以 OpenAI Audio API 为主体，不增加数据库迁移、业务模型、实时 ASR、异步 ASR、双向 TTS 或声音复刻。

## 协议与能力

- TTS JSON 请求增加 `speech_options.sample_rate` 和 `speech_options.context.texts`，保留顶层 `instructions`。
- TTS 支持 8k、16k、24k；引用上文按顺序合并，语音指令最后加入火山 `context_texts`。
- ASR multipart 增加单个 JSON 字符串字段 `speech_options`。
- ASR 开放 ITN、标点、DDC、系统敏感词、VAD、强制分段、说话人、双声道、请求级热词、替换词和文本上下文。
- 渠道管理端增加平台级 ASR 热词表 ID，并补齐七种前端语言。
- `verbose_json` 的 segment 和 word 增加可选 `speaker`、`channel`；增加厂商中立 `annotations` 协议结构。
- 未知字段、模式不适用字段和当前资源未验证字段返回 `400`，不允许资源 ID、鉴权或火山原始请求体透传。

## 真实能力边界

- 当前账号已验证 TTS 8k/16k/24k、生产默认 Vivi 2.0、云舟 2.0 和 `context_texts`。
- 当前账号已验证 ASR 显式开关、说话人、敏感词、VAD/强制分段、热词、替换词和文本上下文；替换词实际改变转写结果。
- 双声道验证确认必须使用 `enable_channel_split=true` 并声明 `audio.channel=2`，返回分句 `channel_id`。
- 图片上下文请求虽返回成功，但当前 `volc.bigasr.auc_turbo` 没有可证明的模型效果；音乐/POI 开关也未返回结构化结果，因此三项均不开放。
- 极速接口明确移除 LID、情绪、性别、音量和语速检测。

完整矩阵见 `docs/volc-speech-capability-matrix.md`。

## 计费与隐私

- TTS 仍按火山 `usage.text_words` 结算。
- ASR 仍按火山实际音频时长结算。
- 语音日志只增加选项名称、布尔状态和上下文/热词/替换词数量，不记录正文、指令、图片 URL、词表内容或音频。
- 所有开放能力继续使用原 TTS/ASR 资源，不改变网关定价公式。
- 新候选上线前必须用隔离请求核对火山控制台用量/账单增量，或取得明确的官方计费确认；网关公式不变不能单独证明上游没有能力附加费。
