# v1.0.0-rc.22-sxh.8

## 图生图参数兼容

- OpenAI 兼容图生图 multipart 请求支持渠道参数删除规则，可按映射后的上游模型和接口匹配。
- 保留多值字段、图片和 mask；每次渠道尝试独立应用规则。透传重试恢复原始请求长度和 Content-Type，清理上一渠道的删除审计。
- 条件匹配使用可信路由上下文；未命中的其他接口操作跳过，命中的不支持操作明确报错。
- 不增加计费字段转换能力。数量、尺寸、质量等字段禁止删除；透传与参数规则同时启用会报错。
- 无数据库结构、新增环境变量或前端业务改动。

## 验证

- 全量 Go 测试通过；图像与参数覆盖相关 race 测试通过。
- 回归覆盖多图、mask、多值字段、条件匹配、上下文防覆盖、非法规则和跨渠道透传重试。
- 前端类型检查和生产构建通过。候选镜像独立数据库启动后结构不变；模拟上游验证模型映射、参数删除、图片字节及请求长度，失败请求退还预扣额度。

## 配置与回滚

- 配置参考 `docs/configuration/image-multipart-overrides.md`。仅针对确认不支持的参数配置删除，不自动猜测上游错误。
- 现有无条件覆盖规则必须先检查 multipart 兼容性；JSON 专用规则可使用 `request_headers.content-type` 条件限定。
- 发布保留旧镜像、Compose、SQLite 一致性备份和所改渠道配置前像；应用回滚只切回镜像，必要时只恢复本次修改的配置，不覆盖业务数据库。
