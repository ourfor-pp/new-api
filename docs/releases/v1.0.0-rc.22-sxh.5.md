# v1.0.0-rc.22-sxh.5 候选版本日志

## 版本目标

本候选版本在 `v1.0.0-rc.22-sxh.4` 字幕时间轴能力上合入后续 code review 修订。`.5` 取代旧 `.4` 候选，避免同一版本号对应不同提交和镜像。

本版本只准备候选代码和发布记录，不自动构建镜像、部署生产、修改数据库或调整渠道。

## 修复与文档

- ASR multipart 在首次解析时统一合并 `timestamp_granularities` 与 `timestamp_granularities[]`，删除验证层的重复整包解析。
- 保持可回放 `BodyStorage` 的流式解析，不把磁盘缓存的大文件整体读回内存。
- TypeScript TTS SSE 示例仅在收到 `speech.audio.done` 后使用音频和字幕；提前结束时丢弃全部未完成结果。
- SSE 示例在拼接网络分块后规范化 CRLF，兼容行结束符跨分块。
- 客户端接入文档补充常用 Seed-TTS 2.0 音色、直接指定 speaker ID 的示例，以及火山官方动态音色目录和 `ListSpeakers` 查询入口。
- OpenAPI 补充 ASR 纯文本、SRT 和 WebVTT 成功响应类型。
- 增加 SXH Fork、火山语音维护和生产运维 Skill，以及维护交接文档。
- 明确生产数据库验证基线的复用、一次性工作副本、配置指纹和刷新条件。
- 增加候选全部预准备、监控在途请求并等待连续空窗后快速切换的最小停机流程。

## 兼容性

- 普通 TTS MP3、Opus、PCM 裸音频响应不变。
- ASR `json`、`text`、`verbose_json`、SRT、VTT 的服务端响应语义不变。
- 业务模型映射、语音计费、渠道重试、失败退款和审计字段不变。
- 不包含数据库迁移、配置变更或生产操作。
