# v1.0.0-rc.22-sxh.7

## ASR 资源直接映射

- 渠道模型映射直接选择火山录音文件识别资源：`sxh-asr → volc.seedasr.auc` 使用 2.0，`sxh-asr → volc.bigasr.auc_turbo` 使用 1.0 极速版。
- 删除 `doubao-seed-asr-flash` 自定义标识，不增加渠道配置字段。保留客户端 `sxh-asr`、同步转写接口、文件上传和原有响应格式。
- 映射后的资源贯穿请求校验、时长预扣、火山请求头、结果结算和审计；业务模型仍负责权限和销售定价。
- 后台渠道测试按映射后的语音模型选择接口和合法音频，同时保留业务模型用于计费。
- TTS、其他供应商、数据库结构和计费公式不变。
- Review 修订：ASR 校验错误不再固定写 1.0 资源；后台 ASR 渠道测试仅记录响应字节数，不输出识别正文。

- 全量 Go 测试、语音定向 race、前端类型检查与生产构建通过。
- 覆盖两代资源的映射路由、合法音频渠道测试、请求头、审计资源、时长预扣和原业务模型保留。

## 发布与回滚

- 新镜像启动前需把生产渠道旧 ASR 映射改为真实资源 ID，并删除渠道模型列表中的旧标识；不得让新旧配置混用。
- 保留上线前数据库一致性备份、渠道原始配置和旧镜像；回滚时只恢复本次变更的渠道配置和应用镜像，不恢复整库覆盖新交易。
- `volc.seedasr.auc` 已在当前账号通过极速接口实测，用户确认控制台归入 2.0。其他资源仍需核对权限和接口兼容性。
